# 晾衣绳整理与显示控制：开发验收

2026-10-14。本项为下一版本开发，未发布新二进制，Info.plist 仍为已发布的 0.1.3。

## 行为

- 工具栏增加明确的一键整理文字；设置与菜单提供相同入口，恢复当前查看周的日期顺序。
- 设置第一组新增晾衣绳启用开关，关闭后立即隐藏。固定展示、启动和顶部触发均受总开关约束；重启仍关闭。
- 停用时菜单栏点击记一行；右键菜单仍有回顾、设置、整理与重新启用。快捷键展开在停用时打开设置。
- 顶部悬停展开独立控制，新安装默认关闭；已有 edgeReveal 等偏好保持原值，不重置语言或材质。
- 悬停连续 0.6 秒后才展开；离开触发区、停用、收起或休眠会取消待展开操作。
